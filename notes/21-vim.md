# Vim 详尽操作手册

## 1. 工作模式概览

| 模式     | 名称         | 进入方式                            | 主要用途                             | 退出方式                 |
|----------|--------------|-------------------------------------|--------------------------------------|--------------------------|
| 普通模式 | Normal       | 启动Vim后默认，或按`Esc`            | 移动光标、删除、复制、粘贴、执行命令 | -                        |
| 插入模式 | Insert       | `i` `a` `o` `I` `A` `O` 等          | 输入/修改文本                        | `Esc` 返回普通模式       |
| 可视模式 | Visual       | `v` (字符), `V` (行), `Ctrl+v` (块) | 选择文本区域进行操作                 | `Esc` 或按相同键         |
| 命令模式 | Command-line | 普通模式下按`:` `/` `?` `!`         | 执行Ex命令、搜索、过滤、保存、退出   | `Enter` 执行，`Esc` 取消 |
| 替换模式 | Replace      | 普通模式下按`R`                     | 覆盖方式输入文本                     | `Esc`                    |

## 2. 光标移动（普通模式）

### 2.1 基本移动

| 按键 | 功能                     | 按键 | 功能                       |
|------|--------------------------|------|----------------------------|
| `h`  | 左移一个字符             | `j`  | 下移一行                   |
| `k`  | 上移一行                 | `l`  | 右移一个字符               |
| `0`  | 移动到行首（第一个字符） | `^`  | 移动到行首第一个非空白字符 |
| `$`  | 移动到行尾               | `g_` | 移动到行尾非空白字符       |
| `w`  | 下一个单词开头           | `W`  | 下一个单词开头（忽略标点） |
| `b`  | 当前/上一个单词开头      | `B`  | 同上（忽略标点）           |
| `e`  | 当前/下一个单词结尾      | `E`  | 同上（忽略标点）           |
| `ge` | 上一个单词结尾           | `gE` | 同上（忽略标点）           |

### 2.2 跳转与翻页

| 按键         | 功能                       | 按键     | 功能                   |
|--------------|----------------------------|----------|------------------------|
| `gg`         | 跳转到文件第一行           | `G`      | 跳转到文件最后一行     |
| `nG` 或 `:n` | 跳转到第 n 行              | `:0`     | 跳转到第一行           |
| `H`          | 跳转到屏幕顶部             | `M`      | 跳转到屏幕中间         |
| `L`          | 跳转到屏幕底部             | `zt`     | 当前行置顶             |
| `zz`         | 当前行置中                 | `zb`     | 当前行置底             |
| `Ctrl+f`     | 向下翻一页                 | `Ctrl+b` | 向上翻一页             |
| `Ctrl+d`     | 向下翻半页                 | `Ctrl+u` | 向上翻半页             |
| `%`          | 跳转到匹配的括号`{} [] ()` | `gd`     | 跳转到局部变量定义     |
| `*`          | 搜索当前单词并向下跳转     | `#`      | 搜索当前单词并向上跳转 |

### 2.3 标记与跳转

| 按键     | 功能                     | 按键         | 功能                   |
|----------|--------------------------|--------------|------------------------|
| `m{a-z}` | 设置局部标记（当前文件） | `m{A-Z}`     | 设置全局标记（跨文件） |
| `'{a-z}` | 跳转到标记所在行首       | `` `{a-z} `` | 跳转到标记所在列       |
| `''`     | 跳回上一个位置           | ``           | 跳回上一个列位置       |
| `Ctrl+o` | 后退到上一个位置         | `Ctrl+i`     | 前进到下一个位置       |

| `S`  | 删除当前行并进入插入模式 | `cc` | 删除当前行并进入插入模式   |
| `C`  | 从光标删除到行尾并插入   | `R`  | 进入替换模式（覆盖输入）   |

## 4. 删除、复制与粘贴

| 操作           | 按键              | 说明                         |
|----------------|-------------------|------------------------------|
| 删除字符       | `x`               | 删除光标下字符（等同于`dl`） |
|                | `X`               | 删除光标前字符（`dh`）       |
| 删除单词       | `dw`              | 删除到下一个单词开头         |
|                | `daw`             | 删除整个单词（含空格）       |
|                | `diw`             | 删除整个单词（不含空格）     |
| 删除行         | `dd`              | 删除当前行                   |
|                | `D`               | 删除从光标到行尾             |
|                | `d0`              | 删除从光标到行首             |
|                | `dgg`             | 删除从当前行到文件开头       |
|                | `dG`              | 删除从当前行到文件末尾       |
| 删除到匹配括号 | `d%`              | 删除到匹配的`{} [] ()`       |
| 删除括号内内容 | `di(` `di{` `di[` | 删除括号内所有内容           |
| 复制           | `yy`              | 复制当前行                   |
|                | `yw`              | 复制一个单词                 |
|                | `yaw`             | 复制整个单词                 |
|                | `y$`              | 复制到行尾                   |
|                | `y0`              | 复制到行首                   |
|                | `yG`              | 复制到文件末尾               |
|                | `ygg`             | 复制到文件开头               |
| 粘贴           | `p`               | 在光标后粘贴                 |
|                | `P`               | 在光标前粘贴                 |
|                | `gp`              | 粘贴并移动光标到粘贴内容末尾 |
| 交换字符/行    | `xp`              | 交换光标后两个字符           |
|                | `ddp`             | 交换当前行与下一行           |

## 6. 修改与替换

| 按键       | 功能                                 | 等效操作 |
|------------|--------------------------------------|----------|
| `r`        | 替换光标下单个字符（不进入插入模式） | -        |
| `R`        | 进入替换模式（连续覆盖）             | -        |
| `~`        | 切换光标下字符大小写                 | -        |
| `guw`      | 将单词转换为小写                     | -        |
| `gUw`      | 将单词转换为大写                     | -        |
| `guu`      | 整行小写                             | -        |
| `gUU`      | 整行大写                             | -        |
| `g~aw`     | 切换整个单词大小写                   | -        |
| `cw`       | 删除到单词结尾并进入插入模式         | `dw i`   |
| `caw`      | 删除整个单词（含空格）并插入         | -        |
| `ciw`      | 删除整个单词（不含空格）并插入       | -        |
| `cc`       | 删除整行并插入                       | `dd i`   |
| `C`        | 删除到行尾并插入                     | `D i`    |

## 7. 搜索与替换

### 7.1 搜索

| 命令       | 功能                   |
|------------|------------------------|
| `/pattern` | 向下搜索 pattern       |
| `?pattern` | 向上搜索 pattern       |
| `n`        | 向同一方向重复搜索     |
| `N`        | 向反方向重复搜索       |
| `*`        | 搜索光标下单词（向下） |
| `#`        | 搜索光标下单词（向上） |
| `:noh`     | 取消高亮搜索结果       |

### 7.2 替换（Ex命令）

| 命令                     | 说明                         |
|--------------------------|------------------------------|
| `:s/old/new`             | 替换当前行第一个 old         |
| `:s/old/new/g`           | 替换当前行所有 old           |
| `:s/old/new/gc`          | 替换当前行，逐个确认         |
| `:n,ms/old/new/g`        | 替换 n 到 m 行之间的所有 old |
| `:%s/old/new/g`          | 替换整个文件所有 old         |
| `:%s/old/new/gc`         | 全局替换，逐个确认           |
| `:%s/old/new/gi`         | 忽略大小写替换               |
| `:g/pattern/s/old/new/g` | 在匹配 pattern 的行中替换    |
| `:v/pattern/s/old/new/g` | 在不匹配 pattern 的行中替换  |

## 8. 可视模式操作

| 按键               | 功能                                                                                                                                                           |
|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `v`                | 进入字符可视模式                                                                                                                                               |
| `V`                | 进入行可视模式                                                                                                                                                 |
| `Ctrl+v`           | 进入块可视模式                                                                                                                                                 |
| `gv`               | 重新选择上一次的可视区域                                                                                                                                       |
| `o`                | 在可视模式下移动光标到选区另一端                                                                                                                               |

## 9. 多文件与窗口管理

### 9.1 缓冲区操作

| 命令                    | 功能                                           |
|-------------------------|------------------------------------------------|
| `:e filename`           | 打开新文件到当前缓冲区                         |
| `:bnext` 或 `:bn`       | 切换到下一个缓冲区                             |
| `:bprev` 或 `:bp`       | 切换到上一个缓冲区                             |
| `:bfirst` 或 `:brewind` | 切换到第一个缓冲区                             |
| `:blast`                | 切换到最后一个缓冲区                           |
| `:ls`                   | 列出所有缓冲区                                 |
| `:b2`                   | 切换到编号为 2 的缓冲区                        |
| `:bd`                   | 删除缓冲区（关闭文件）                         |
| `:bd!`                  | 强制删除不保存                                 |
| `:bufdo`                | 对每个缓冲区执行命令，如`:bufdo %s/foo/bar/gc` |

### 9.2 分割窗口

| 命令               | 功能                        |
|--------------------|-----------------------------|
| `:sp` 或 `:split`  | 水平分割窗口（当前文件）    |
| `:sp filename`     | 水平分割并打开文件          |
| `:vs` 或 `:vsplit` | 垂直分割窗口                |
| `Ctrl+w s`         | 水平分割当前窗口            |
| `Ctrl+w v`         | 垂直分割当前窗口            |
| `Ctrl+w w`         | 在窗口间循环跳转            |
| `Ctrl+w h/j/k/l`   | 移动到左/下/上/右窗口       |
| `Ctrl+w H/J/K/L`   | 移动当前窗口到最左/下/上/右 |
| `Ctrl+w =`         | 平均分配窗口尺寸            |
| `Ctrl+w _`         | 最大化当前窗口高度          |
| `Ctrl+w \|`        | 最大化当前窗口宽度          |
| `Ctrl+w o`         | 关闭其他窗口，只保留当前    |
| `:q` 或 `Ctrl+w c` | 关闭当前窗口                |
| `Ctrl+w q`         | 关闭当前窗口（同`:q`）      |

### 9.3 标签页

| 命令                   | 功能                |
|------------------------|---------------------|
| `:tabnew`              | 新建空白标签页      |
| `:tabnew file`         | 在新标签页打开文件  |
| `gt` 或 `:tabnext`     | 下一个标签页        |
| `gT` 或 `:tabprev`     | 上一个标签页        |
| `ngt`                  | 跳转到第 n 个标签页 |
| `:tabclose` 或 `:tabc` | 关闭当前标签页      |
| `:tabonly`             | 关闭其他标签页      |
| `:tabmove 2`           | 移动标签页到位置 2  |

| 步骤        | 操作             |
|-------------|------------------|

## 17. Vim 配置文件 .vimrc 常用设置

```vim
" 基础配置
set number              " 显示行号
set relativenumber      " 相对行号
set autoindent
set tabstop=4
set shiftwidth=4
set expandtab           " 空格代替tab
set hlsearch
set incsearch
set ignorecase
set smartcase
syntax on
set mouse=a
set clipboard=unnamedplus

" 映射 leader 键
let mapleader = " "
" 快速保存
nnoremap <Leader>w :w<CR>
" 快速退出
nnoremap <Leader>q :q<CR>
" 取消高亮
nnoremap <Leader>h :noh<CR>
" 重新加载 .vimrc
nnoremap <Leader>sv :source $MYVIMRC<CR>
```

$\text{诱导公式：}\sin\left( \frac{n\pi}{2} + \alpha \right) = \left\{ \begin{array}{r} ( - 1)^{\frac{n}{2}}\sin\alpha\ \ \ \ \ \ (n\text{是偶数}) \\ ( - 1)^{\frac{n - 1}{2}}\cos\alpha\ \ (n\text{是奇数}) \end{array} \right.\ \text{，}\cos\left( \frac{n\pi}{2} + \alpha \right) = \left\{ \begin{array}{r} ( - 1)^{\frac{n}{2}}\cos\alpha\ \ \ \ \ \ (n\text{是偶数}) \\ ( - 1)^{\frac{n - 1}{2}}\sin\alpha\ \ (n\text{是奇数}) \end{array} \right.\$

和（差）角公式：$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta \text{，}\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta \text{，}$

$\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta \text{，}\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta \text{，}$

$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}\text{，}\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$

$\text{二倍角公式：}\sin{2\alpha} = 2\sin\alpha\cos\alpha = \frac{2\tan\alpha}{1 + \tan^{2}\alpha}\text{，}\cos{2\alpha} = \cos^{2}\alpha - \sin^{2}\alpha = 2\cos^{2}\alpha - 1 = 1 - 2\sin^{2}\alpha = \frac{1 - \tan^{2}\alpha}{1 + \tan^{2}\alpha}\text{，}\tan{2\alpha} = \frac{2\tan\alpha}{1 - \tan^{2}\alpha}$

$\text{万能公式：}\sin\alpha = \frac{2\tan\frac{\alpha}{2}}{1 + \tan^{2}\frac{\alpha}{2}}\text{，}\cos\alpha = \frac{1 - \tan^{2}\frac{\alpha}{2}}{1 + \tan^{2}\frac{\alpha}{2}}\text{，}\tan\alpha = \frac{2\tan\frac{\alpha}{2}}{1 - \tan^{2}\frac{\alpha}{2}}$

$\text{降幂扩角公式：}\sin^{2}\alpha = \frac{1 - \cos{2\alpha}}{2}\text{，}\cos^{2}\alpha = \frac{1 + \cos{2\alpha}}{2}\text{，}\tan^{2}\alpha = \frac{1 - \cos{2\alpha}}{1 + \cos{2\alpha}}\text{，}\sin\alpha\cos\alpha = \frac{1}{2}\sin{2\alpha}$

$\text{升幂缩角公式：}1 + \cos{2\alpha} = 2\cos^{2}\alpha \text{，}1 - \cos{2\alpha} = 2\sin^{2}\alpha \text{，}1 + \sin{2\alpha} = \left( \sin\alpha + \cos\alpha \right)^{2}\text{，}1 - \sin{2\alpha} = \left( \sin\alpha - \cos\alpha \right)^{2}$

$\text{三倍角公式：}\sin{3\alpha} = 3\sin\alpha - 4\sin^{3}\alpha = 4\sin\alpha\sin\left( \frac{\pi}{3} + \alpha \right)\sin\left( \frac{\pi}{3} - \alpha \right)\text{，}$

$\cos{3\alpha} = - 3\cos\alpha + 4\cos^{3}\alpha = 4\cos\alpha\cos\left( \frac{\pi}{3} + \alpha \right)\cos\left( \frac{\pi}{3} - \alpha \right)\text{，}$

$\tan{3\alpha} = \frac{3\tan\alpha - \tan^{3}\alpha}{1 - 3\tan^{2}\alpha} = \tan\alpha\tan\left( \frac{\pi}{3} + \alpha \right)\tan\left( \frac{\pi}{3} - \alpha \right)$

$\text{和差化积公式：}\sin\alpha + \sin\beta = 2\sin\left( \frac{\alpha + \beta}{2} \right)\cos\left( \frac{\alpha - \beta}{2} \right)\text{，}\sin\alpha - \sin\beta = 2\cos\left( \frac{\alpha + \beta}{2} \right)\sin\left( \frac{\alpha - \beta}{2} \right)\text{，}$

$\cos\alpha + \cos\beta = 2\cos\left( \frac{\alpha + \beta}{2} \right)\cos\left( \frac{\alpha - \beta}{2} \right)\text{，}\cos\alpha - \cos\beta = - 2\sin\left( \frac{\alpha + \beta}{2} \right)\sin\left( \frac{\alpha - \beta}{2} \right)\text{，}$

$\tan\alpha + \tan\beta = \tan(\alpha + \beta)\left( 1 - \tan\alpha\tan\beta \right)\text{，}\tan\alpha - \tan\beta = \tan(\alpha - \beta)\left( 1 + \tan\alpha\tan\beta \right)$

$\text{积化和差公式：}\sin\alpha\sin\beta = - \frac{1}{2}\left\lbrack \cos(\alpha + \beta) - \cos(\alpha - \beta) \right\rbrack \text{，}\sin\alpha\cos\beta = \frac{1}{2}\left\lbrack \sin(\alpha + \beta) + \sin(\alpha - \beta) \right\rbrack \text{，}$

$\cos\alpha\sin\beta = \frac{1}{2}\left\lbrack \sin(\alpha + \beta) - \sin(\alpha - \beta) \right\rbrack \text{，}\cos\alpha\cos\beta = \frac{1}{2}\left\lbrack \cos(\alpha + \beta) + \cos(\alpha - \beta) \right\rbrack$

$\tan\alpha\tan\beta = 1 - \frac{\tan\alpha + \tan\beta}{\tan(\alpha + \beta)} = \frac{\tan\alpha - \tan\beta}{\tan(\alpha - \beta)} - 1$

$\text{半角公式：}\sin\left( \frac{\alpha}{2} \right) = \pm \sqrt{\frac{1 - \cos\alpha}{2}}\text{，}\cos\left( \frac{\alpha}{2} \right) = \pm \sqrt{\frac{1 + \cos\alpha}{2}}\text{，}\tan\left( \frac{\alpha}{2} \right) = \pm \sqrt{\frac{1 - \cos\alpha}{1 + \cos\alpha}} = \frac{\sin\alpha}{1 + \cos\alpha} = \frac{1 - \cos\alpha}{\sin\alpha}$

辅助角公式：$a\sin x \pm b\cos x = \sqrt{a^{2} + b^{2}}\sin(x \pm \varphi)$，其中$\sin\varphi = \frac{b}{\sqrt{a^{2} + b^{2}}}\text{，}\cos\varphi = \frac{a}{\sqrt{a^{2} + b^{2}}}$

$\text{正切定理：}(a + b)/(a - b) = \tan\frac{A + B}{2}/\tan\frac{A - B}{2}$

$\text{面积推论：}S_{\bigtriangleup ABC} = \frac{1}{2}ab\sin C = \frac{1}{2}ac\sin B = \frac{1}{2}bc\sin A$

其它结论：$\sin^{2}\alpha - \sin^{2}\beta = \sin(\alpha + \beta)\sin{(\alpha - \beta)}$，$\cos^{2}\alpha - \cos^{2}\beta = - \sin(\alpha + \beta)\sin(\alpha - \beta)$，$\sin^{2}x = \left( 1 + \cos x \right)\left( 1 - \cos x \right)$

$\frac{\tan\alpha + 1}{1 - tan\alpha} = \tan{(\alpha + \frac{\pi}{4})}\text{，}\frac{\tan\alpha - 1}{1 + \tan\alpha} = \tan\left( \alpha - \frac{\pi}{4} \right)\text{，}\sqrt{3} + \tan\alpha = \frac{2\sin\left( \alpha + \frac{\pi}{3} \right)}{\cos\alpha}\text{，在}x \in \left( 0,\frac{\pi}{2} \right)\text{时，}\sin x < x < \tan x$

$\text{对于}A + B + C = k\pi \text{，}A\text{，}B\text{，}C \notin \frac{\pi}{2} + k\pi \text{，有：}$

$1.\sin A + \sin B + \sin C = 4\cos\frac{A}{2}\cos\frac{B}{2}\cos\frac{C}{2}\text{，}2.\cos A + \cos B + \cos C = 1 + 4\sin\frac{A}{2}\sin\frac{B}{2}\sin\frac{C}{2}$

$3.\tan A + \tan B + \tan C = \tan A\tan B\tan C\text{，}4.\tan\frac{A}{2}\tan\frac{B}{2} + \tan\frac{A}{2}\tan\frac{C}{2} + \tan\frac{B}{2}\tan\frac{C}{2} = 1$

在$\Delta ABC\text{中，有}$：$1.A > B \Leftrightarrow \sin A > \sin B \Leftrightarrow \cos A < \cos B\text{，}2.\sin A = \cos B \Longleftrightarrow A + B = 90{^\circ}\text{，}3.$若$\bigtriangleup ABC$是钝角三角形，则$\sin A > \cos B$

$4.\sin{2A} + \sin{2B} + \sin{2C} = 4\sin A\sin B\sin C$

## 磁感应强度/洛伦兹力

Fm = qv × B

$$B = \frac{F_{m}}{qv} = \frac{dN}{dS}$$

$$qvB = m\frac{v^{2}}{B} \Rightarrow R = \frac{mv}{qB},\ \ T = \frac{2\pi R}{v} = \frac{2\pi m}{qB}$$

毕奥—萨伐尔定律

$$d\mathbf{B} = \frac{\mu_{0}}{4\pi}\frac{Id\mathbf{l} \times \mathbf{r}^{0}}{r^{2}} = \frac{\mu_{0}I}{4\pi r^{2}}d\mathbf{l} \times \mathbf{r}^{0}\ \ \ \ \ \text{对比}d\mathbf{E} = \frac{1}{4\pi\varepsilon_{0}}\frac{dq}{r^{2}}\mathbf{r}^{0}$$

μ0 = 4π × 10−7

### 磁通量

dΦm = B ⋅ dS

### 磁场的高斯定理

Φm = ∮SB ⋅ dS = 0

### 安培环路定理

$$\oint_{L}^{}{\mathbf{B} \cdot d\mathbf{l}} = \mu_{0}\sum_{}^{}I$$

环路右手螺旋拇指指向与电流相同时为正，否则为反。

### 运动点电荷产生的磁场

$$\mathbf{B} = \frac{\mu_{0}}{4\pi}\frac{q\mathbf{v} \times \mathbf{r}^{0}}{r^{2}}$$

安培定律（安培力）

dF = Idl × B

### 线圈的磁矩

pm = NISn

n是垂直于线圈所在平面的单位方向向量。

对应的磁力的力矩（磁力矩）为

M = pm × B

### 带电粒子在磁场中的运动

$$\mathbf{F}_{m} = q\mathbf{v} \times \mathbf{B},\ \ qvB = m\frac{v^{2}}{B} \Rightarrow R = \frac{mv}{qB},\ \ T = \frac{2\pi R}{v} = \frac{2\pi m}{qB}$$

B = μ0μrH = μH = μ0H + μ0M

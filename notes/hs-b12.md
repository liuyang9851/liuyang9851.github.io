# 数论初步

算数基本定理：若整数$n > 1$，则$n$可以写为一系列的质数之积

$n = p_{1}^{\alpha_{1}}p_{2}^{\alpha_{2}}\cdots p_{k}^{\alpha_{k}}$

整除

概念

一般地，设$a\text{，}b$为整数，且$b \neq 0$，如果存在整数$q$，使得$a = bq$，那么称$b$整除$a$，或者$a$能被$b$整除，记作$b\ |\ a$。并且$b$称是$a$的因数，$a$是$b$的倍数，如果这样的整数$q$不存在，就称$b$不整除$a$，记作$b \nmid a$。

性质

1.若$a\ \text{|}\ b\left( b\text{=}0 \right)$，则$|a| \leq |b|$

2.若$a\ |\ b\text{，}b\ |\ a$，则$|a| = |b|$

3.若$a\ |\ b\text{，}b\ |\ c$，则$a\ |\ c$

4.若$a\ \text{|}\ b$，则$ac\ \text{|}\ bc$

5.若$a\ |\ b\text{，}a\ |\ c$，则对于任意整数，恒有$a\ |\ bx + cy$

证明：设符合条件的整数为$A = a_{n}a_{n - 1}\cdots a_{1}a_{0}$

2：因为末位为0的数均是2的倍数，所以只需考察各位数是否是2的倍数。

3：$a_{n}a_{n - 1}\cdots a_{1}a_{0} = a_{n} \times 10^{n} + a_{n - 1} \times 10^{n - 1} + \cdots + a_{1} \times 10 + a_{0}$

$= a_{n} \times \underset{n\text{个}9}{\overset{99\cdots 99}{︸}} + a_{n - 1} \times \underset{n - 1\text{个}9}{\overset{99\cdots 99}{︸}} + \cdots + a_{1} \times 9 + (a_{0} + a_{1} + \cdots + a_{n})$

因为各位均为9的数是3的倍数，所以只需$a_{0} + a_{1} + \cdots + a_{n}$是3的倍数。

4：因为末两位为00的数均是4的倍数，所以只需考察十位和个位组成的数是否是4的倍数。

5：因为末位为0的数均是5的倍数，所以只需考察各位数是否是5的倍数。

6：因为$6 = 2 \times 3$，所以既是2的倍数又是3的倍数即是6的倍数。

7：由

$\frac{A - 100a_{2} - 10a_{1} - a_{0}}{1000} - 100a_{2} - 10a_{1} - a_{0} = 7k\text{，}\left( k \in \mathbb{N}^{*} \right)$

得

${A = \left( 7k + 100a_{2} + 10a_{1} + a_{0} \right) \times 1000 + 100a_{2} + 10a_{1} + a_{0} }{= 700k + 100100a_{2} + 1000a_{1} + 1001a_{0} }{= 7\left( 1000k + 143000a_{2} + 1430a_{1} + 143a_{0} \right)}$

$\text{由}\frac{A - a_{0}}{10} - 2a_{0} = 7k\text{，得}A = 70k + 21a_{0} = 7\left( 10k + 3a_{0} \right)$

8：因为末三位为00的数均是8的倍数，所以只需考察百位，十位和个位组成的数是否是4的倍数。

9：$a_{n}a_{n - 1}\cdots a_{1}a_{0} = a_{n} \times 10^{n} + a_{n - 1} \times 10^{n - 1} + \cdots + a_{1} \times 10 + a_{0}$

$= a_{n} \times \underset{n\text{个}9}{\overset{99\cdots 99}{︸}} + a_{n - 1} \times \underset{n - 1\text{个}9}{\overset{99\cdots 99}{︸}} + \cdots + a_{1} \times 9 + (a_{0} + a_{1} + \cdots + a_{n})$

因为各位均为9的数是9的倍数，所以只需$a_{0} + a_{1} + \cdots + a_{n}$是9的倍数。

11.由

$\frac{A - 100a_{2} - 10a_{1} - a_{0}}{1000} - - 100a_{2} - 10a_{1} - a_{0} = 11k$

得

$A = 11000k + 100100a_{2} + 10010a_{1} + 1001a_{0}$

$= 11\left( 1000k + 9100a_{2} + 910a_{1} + 91a_{0} \right)$

设数为$A = a_{n}a_{n - 1}\cdots a_{2}a_{1}$，由

$a_{1} - a_{2} + a_{3} - a_{4} + \cdots = 11k$

得

$a_{1} = 11k + a_{2} - a_{3} + a_{4} - \cdots$

故

${A = \left( 11k + a_{2} - a_{3} + a_{4} - \cdots \right) + 10a_{2} + 100a_{3} + 1000a_{4} + \cdots }{= 11k + 11a_{2} + 99a_{3} + 1001a_{4} + \cdots }{= 11\left( k + a_{2} + 9a_{3} + 91a_{4} + \cdots \right)}$

带余除法（欧式除法算式）

一般地，设为整数，且设$a\text{，}b$为整数，且$b \neq 0$，则存在唯一的一对整数和$r$，使得

$a = bq + r\text{，}0 \leq r < |b|$

其中$q$称为$a$除以$b$的商，$r$称为$a$除以$b$的余数。

最大公约数和最小公倍数

最大公约数：$(a,b)$

最小公倍数：$\lbrack a.b\rbrack$

$(a,b) \cdot \lbrack a,b\rbrack = ab$

翡蜀定理

仅有两个正因数的正整数是素数。不是素数又不是1的正整数为合数。1既不是素数，也不是合数

筛法

如果大于$1$的整数$a$不能被所有不超过$\sqrt{a}$的素数整除，那么$a$一定是素数。

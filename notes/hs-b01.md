对称性与轮换性

对称性：任意两个字母交换，代数式不变。$eg.xy + yz + zx$

轮换性：有顺序地改变所有字母的位置，代数式不变。$eg.x^{2}y + y^{2}z + z^{2}x$

两对称式加减乘除后仍为对称式，两轮换式加减乘除后仍为轮换式。

因式分解初探

定义

把一个多项式在一个范围（如实数范围内分解，即所有项均为实数）化为几个整式的积的形式，这种式子变形叫做这个多项式的因式分解，也叫作把这个多项式分解因式。

原则

1、分解因式是多项式的恒等变形，要求等式左边必须是多项式。

2、分解因式的结果必须是以乘积的形式表示。

3、每个因式必须是整式，且每个因式的次数都必须低于原来多项式的次数。

4、结果最后只留下小括号，分解因式必须进行到每一个多项式因式都不能再分解为止；

5、结果的多项式首项一般为正。 在一个公式内把其公因子抽出，即透过公式重组，然后再抽出公因子；

6、括号内的首项系数一般为正；

7、如有单项式和多项式相乘，应把单项式提到多项式前。如$(b + c)a$要写成$a(b + c)$；

8、没有说明化到实数时，一般只化到有理数，有说明实数的话，就要化到实数。

代数基本定理与因式分解

因式分解的方法

提公因式法

如果一个多项式的各项有公因式，可以把这个公因式提出来，从而将多项式化成两个因式乘积的形式，这种分解因式的方法叫做提公因式法。

$eg.2a(b + c) - 3(b + c) = (b + c)(2a - 3)$

公式法

如果把乘法公式的等号两边互换位置，就可以得到用于分解因式的公式，用来把某些具有特殊形式的多项式分解因式，这种分解因式的方法叫做公式法。

$eg.(x + p)^{2} - (x + q)^{2} = (2x + p + q)(p - q)$

$x^{4} - y^{4} = \left( x^{2} + y^{2} \right)\left( x^{2} - y^{2} \right) = \left( x^{2} + y^{2} \right)(x + y)(x - y)$

$a^{3}b - ab = ab\left( a^{2} - 1 \right) = ab(a + 1)(a - 1)$

$\left( a^{2} + b^{2} - 1 \right)^{2} - 4a^{2}b^{2} = \left( a^{2} + b^{2} - 1 + 2ab \right)\left( a^{2} + b^{2} - 1 - 2ab \right) = \left\lbrack (a + b)^{2} - 1 \right\rbrack\left\lbrack (a - b)^{2} - 1 \right\rbrack = (a + b + 1)(a + b - 1)(a - b + 1)(a - b - 1)$

（单）十字相乘法

对于形如$kx^{2} + mx + n$的式子，如果存在$a\text{，}b\text{，}c\text{，}d\mathbb{\in R}$，使得$(ax + b)(cx + d) = kx^{2} + mx + n$，即$k = ac\text{，}n = bd\text{，}m = ad + bc$，这种分解因式的方法叫做十字相乘法。

$eg.6x^{2} + 13x + 6 = (2x + 3)(3x + 2)$

长十字相乘法

对于形如$Ax^{2} + Bxy + Cy^{2} + Dx + Ey + F = 0$的式子（$x\text{，}y$为未知数，其余都是常数），用三次十字相乘法分解因式，这种分解因式的方法叫做长十字相乘法。长十字相乘法是双十字相乘法的前身。

若有二次式$Ax^{2} + Bxy + Cy^{2} + Dx + Ey + F = (ax + by + c)(dx + ey + f)$，则

$\left\{ \begin{array}{r} Ax^{2} + Bxy + Cy^{2} = (ax + by)(dx + ey) \\ Ax^{2} + Dx + F = (ax + c)(dx + f)\ \ \ \ \ \ \ \ \ \ \ \  \\ Cy^{2} + Ey + F = (by + c)(cy + f)\ \ \ \ \ \ \ \ \ \ \ \ \ \end{array} \right.\$

整体上写作

$Ax^{2} + Bxy + Cy^{2} + Dx + Ey + F$

$\begin{matrix} a\ \ \ \ \ \ \ \ \ \ \ \ \ \ \  & b & \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ c \\ d\ \ \ \ \ \ \ \ \ \ \ \ \ \ \  & e & \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ f \end{matrix}$

$eg.2x^{2} - 7xy - 22y^{2} - 5x + 35y - 3 = (x + 2y - 3)(2x - 11y + 1)$

$\begin{matrix} 1 & 2 & - 3 \\ 2 & - 11 & 1 \end{matrix}$

双十字相乘法

对于形如$Ax^{2} + Bxy + Cy^{2} + Dx + Ey + F = 0$的式子（$x\text{，}y$为未知数，其余都是常数），用两次十字相乘法分解因式，这种分解因式的方法叫做双十字相乘法。

对于可被分解为形如$(ax + by + c)(dx + ey + f)$二次式$Ax^{2} + Bxy + Cy^{2} + Dx + Ey + F = 0$，将其按$x$（或$y$）降幂排列为$Ax^{2} + (By + D)x + \left( Cy^{2} + Ey + F \right)$，若对$\left( Cy^{2} + Ey + F \right)$能因式分解为形如$(by + c)(cy + f)$的形式，则尝试用十字相乘法分解$Ax^{2} + (By + D)x + (by + c)(cy + f)$。

$eg.2x^{2} - 7xy - 22y^{2} - 5x + 35y - 3$

解：对$- 22y^{2} + 35y - 3$因式分解，得$- 22y^{2} + 35y - 3 = ( - 11y - 1)(2y + 3)$

对$2x^{2} - (7y + 5)x + ( - 11y - 1)(2y + 3)$因式分解，得

$\begin{matrix} 2x & ( - 11y - 1) \\ 1x & (2y + 3) \end{matrix}$

则$2x^{2} - 7xy - 22y^{2} - 5x + 35y - 3 = \left\lbrack 2x + ( - 11y - 1) \right\rbrack\left\lbrack x + (2y + 3) \right\rbrack$

轮换对称法

$eg.x^{2}(y - z) + y^{2}(z - x) + z^{2}(x - y)$

解：把它看作关于x的多项式，即

$(y - z)x^{2} + \left( z^{2} - y^{2} \right)x + yz(y - z) = 0$

能得到因式$(y - z)$。由轮换性，还含有因式$(x - y)$、$(z - x)$。由多项式的最高次数为3，得到因式分解的结果为$k(x - y)(y - z)(z - x)$，为确定系数$k$，考虑$x^{2}y$项的系数，得到$k = - 1$，即

$x^{2}(y - z) + y^{2}(z - x) + z^{2}(x - y) = - (x - y)(y - z)(z - x)$

$eg.x^{3}(y - z) + y^{3}(z - x) + z^{3}(x - y)$

解：类似地，得到因式$(x - y)(y - z)(z - x)$，但由于次数高出一次，由轮换性，还含有因式$(x + y + z)$，即

$x^{3}(y - z) + y^{3}(z - x) + z^{3}(x - y) = k(x + y + z)(x - y)(y - z)(z - x)$。考虑$x^{3}y$项，得到$k = 1$，即

$x^{3}(y - z) + y^{3}(z - x) + z^{3}(x - y) = (x + y + z)(x - y)(y - z)(z - x)$

$eg.(x + y + z)^{3} - (y + z - x)^{3} - (z + x - y)^{3} - (x + y - z)^{3}$

解：当$x = 0$时原式为0，因此含有因式$xyz$，又由最高次数为3，得到$kxyz$，对比系数得$k = 24$。

分组分解法

添拆项法

$Ax^{2} + 2Bxy + Cy^{2} + 2Dx + 2Ey + F$

$= Ax^{2} + 2Byx + 2Dx + Cy^{2} + 2Ey + F$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{AC - B^{2}}{A}y^{2} + \frac{2(AE - BD)}{A} + \frac{AF - D^{2}}{A}$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{1}{A}\left\lbrack \left( AC - B^{2} \right)y^{2} + 2(AE - BD) + AF - D^{2} \right\rbrack$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{1}{A}\left\lbrack \left( \sqrt{AC - B^{2}}y + \frac{AE - BD}{\sqrt{AC - B^{2}}} \right)^{2} + \frac{\left( AF - D^{2} \right)\left( AC - B^{2} \right) - (AE - BD)^{2}}{AC - B^{2}} \right\rbrack$

其中

$\frac{\left( AF - D^{2} \right)\left( AC - B^{2} \right) - (AE - BD)^{2}}{AC - B^{2}} = \frac{A^{2}CF - AB^{2}F - ACD^{2} + B^{2}D^{2} - A^{2}E^{2} - B^{2}D^{2} + 2ABDE}{AC - B^{2}} = \frac{A^{2}CF - AB^{2}F - ACD^{2} - A^{2}E^{2} + 2ABDE}{AC - B^{2}}$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{1}{A}\left\lbrack \left( \sqrt{AC - B^{2}}y + \frac{AE - BD}{\sqrt{AC - B^{2}}} \right)^{2} + \frac{A^{2}CF - AB^{2}F - ACD^{2} - A^{2}E^{2} + 2ABDE}{AC - B^{2}} \right\rbrack$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{1}{A}\left( \sqrt{AC - B^{2}}y + \frac{AE - BD}{\sqrt{AC - B^{2}}} \right)^{2} + \frac{ACF - B^{2}F - CD^{2} - AE^{2} + 2BDE}{AC - B^{2}}$

$= \left( \sqrt{A}x + \frac{B}{\sqrt{A}}y + \frac{D}{\sqrt{A}} \right)^{2} + \frac{1}{A}\left( \sqrt{AC - B^{2}}y + \frac{AE - BD}{\sqrt{AC - B^{2}}} \right)^{2} + \frac{1}{AC - B^{2}}\left| \begin{matrix} A & B & D \\ B & C & E \\ D & E & F \end{matrix} \right|$

得到二次式$Ax^{2} + 2Bxy + Cy^{2} + 2Dx + 2Ey + F$的最小值为

$\frac{1}{AC - B^{2}}\left| \begin{matrix} A & B & D \\ B & C & E \\ D & E & F \end{matrix} \right|$

这与二次曲线的判别式相同。

$\sqrt{a \pm \sqrt{b}} = \sqrt{\frac{a + \sqrt{a^{2} - b}}{2}} \pm \sqrt{\frac{a - \sqrt{a^{2} - b}}{2}}\ \ \left( a^{2} \geq b \right)$

$f(n) = \log_{n}(n + m) \Rightarrow f(x + 1) - f(n)$

> $= \log_{n + 1}(n + m + 1) - \log_{n}(n + m)$
>
> $= \log_{n + 1}\frac{n + m + 1}{n + 1} + 1 - \left( \log_{n}\frac{n + m}{n} + 1 \right)$
>
> $< \log_{n}\frac{n + m + 1}{n + 1} - \log_{n}\frac{n + m}{n}$
>
> $< \log_{n}\frac{n + m}{n} - \log_{n}\frac{n + m}{n} = 0$

所以$\log_{2}(2 + m) < \log_{3}(3 + m) < \cdots < \log_{n}(n + m)$

$\log_{x - a}x - \log_{x}(x + a) = \frac{\ln^{2}x}{\ln(x - a) \cdot \ln(x + a)} > \frac{\ln^{2}x}{\frac{1}{4}\left\lbrack \ln(x - a) + \ln(x + a) \right\rbrack^{2}} = \left( \frac{2\ln x}{\ln\left( x^{2} - a^{2} \right)} \right)^{2} = \left( \frac{\ln x^{2}}{\ln\left( x^{2} - a^{2} \right)} \right)^{2} > 1$

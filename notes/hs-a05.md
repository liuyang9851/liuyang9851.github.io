# 平面向量

平面向量基本定理

如果两个向量$\mathbf{a}\text{、}\mathbf{b}$不共线，那么向量$\mathbf{p}$与向量$\mathbf{a}\text{、}\mathbf{b}$共面的充要条件是：存在唯一实数对$x\text{、}y$（$x\text{、}y$不全为零），使得

$p = x\mathbf{a} + y\mathbf{b}$

海伦——秦九韶公式

在$\bigtriangleup ABC$中，设$p = \frac{1}{2}(a + b + c)$，则

$S_{\bigtriangleup ABC} = \sqrt{p(p - a)(p - b)(p - c)}$

极化恒等式

记$\bigtriangleup ABC\text{中}BC\text{边上的中点为}D\text{，则}$

$\overrightarrow{AB} \cdot \overrightarrow{AC} = AD^{2} - \left( \frac{1}{2}BC \right)^{2}$

定比分点公式

$\overset{\rightarrow}{OP} = \lambda\overset{\rightarrow}{OA} + (1 - \lambda)\overset{\rightarrow}{OB}$

或设$|PA|:|PB| = m:n$，则

$\overrightarrow{OP} = \frac{n}{m + n}\overset{\rightarrow}{OA} + \frac{m}{m + n}\overset{\rightarrow}{OB}$

设A$A\left( x_{1}\text{，}y_{1} \right)\text{，}B\left( x_{2}\text{，}y_{2} \right)$，$\overrightarrow{AP} = \lambda\overrightarrow{PB}$，则

$P\left( \frac{x_{1} + \lambda x_{2}}{1 + \lambda}\text{，}\frac{y_{1} + \lambda y_{2}}{1 + \lambda} \right)$

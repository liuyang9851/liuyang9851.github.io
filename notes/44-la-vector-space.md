# 向量与线性空间

[[toc]]

向量与线性空间

线性空间

设𝕂是一个数域，𝕂是一个集合，在V上定义了一个加法“+”，即对V为中任意两个元素α，β，总存在V中唯一的元素γ与之对应，记为γ = α + β。在数域𝕂与之间定义了一种运算，称为数乘，即对𝕂中任一数k及V中任一元素α，在V中总有唯一的元素δ与之对应，记为δ = k ⋅ α=kα。若上述加法及数乘满足下列运算规则：

（1）加法交换律：α + β = β + α

（2）加法结合律：(α + β) + γ = α + (β + γ)

（3）零向量：在中存在一个元素0，对于中任一元素α，都有α + 0 = α，称0为零向量

（4）负向量：对于V中每个元素α，存在元素β，使α + β = 0，并记β = −α

（5）：1 ⋅ α = α

（6）左分配律：k(α + β) = kα + kβ

（7）右分配律：(k + l)α=kα+lβ

（8）数乘结合律：k(lα) = (kl)α

则称V为𝕂上的线性空间/向量空间

上面对“向量”定义事实上与所学的平面向量和空间向量相匹配，从这种意义上看，向量的交换律、结合律、分配律实际上是“无需证明”的。

除了定义中给出的法则，线性空间中的向量满足如下性质，这些性质大多数显而易见，但都是需要证明的：

（1）零向量是唯一的

（2）一个向量的负向量是唯一的

（3）α + β = α + γ ⇒ β = γ，即加法消去律成立

（4）0与任意向量的数乘为零向量

（5）零向量与任意数的数乘为零向量

（6）−1与任一向量的数乘为该向量的反向量

（7）若kα = 0，则α = 0或k = 0

（8）−(−α) = α

（9）−(kα) = (−k)α = k(−α)

（10）k(α − β) = kα − kβ

证明：

（1）设01，02为V中两个零向量，则由运算规则（3），得

01 = 01 + 02 = 02

这就说明任意两个零向量是相等的，即零向量是唯一的。

（2）设α，β1，β2为V中三个向量，且

α + β1 = 0，α+β2 = 0

则

$$\mathbf{\beta}_{1}\overset{3}{\mathbf{=}}\mathbf{\beta}_{1}\mathbf{+ 0}\overset{2}{\mathbf{=}}\mathbf{\beta}_{1}\mathbf{+}\left( \mathbf{\alpha +}\mathbf{\beta}_{2} \right)\overset{2}{\mathbf{=}}\left( \mathbf{\beta}_{1}\mathbf{+ \alpha} \right)\mathbf{+}\mathbf{\beta}_{2}\overset{1}{\mathbf{=}}\left( \mathbf{\alpha +}\mathbf{\beta}_{1} \right)\mathbf{+}\mathbf{\beta}_{2}\overset{1}{\mathbf{=}}\mathbf{0 +}\mathbf{\beta}_{2}\overset{2}{\mathbf{=}}\mathbf{\beta}_{2}$$

等号上面的数字代表用到的运算规则。

（3）

$$
\left( \mathbf{- a} \right)\mathbf{+}\left( \mathbf{\alpha + \beta} \right)\mathbf{=}\left( \mathbf{- \alpha} \right)\mathbf{+}\left( \mathbf{\alpha + \gamma} \right)\overset{2}{\Rightarrow}\left( \left( \mathbf{- \alpha} \right)\mathbf{+ \alpha} \right)\mathbf{+ \beta =}\left( \left( \mathbf{- \alpha} \right)\mathbf{+ \alpha} \right)\mathbf{+ \gamma}\overset{4}{\Rightarrow}\mathbf{0 + \beta = 0 + \gamma}\overset{3}{\Rightarrow}\mathbf{\beta = \gamma}
$$

向量组的线性关系

线性组合与线性表示

设V是数域𝕂上的线性空间，α1，α2，⋯，αn和β均是V中的向量，若存在𝕂中的n个数k1，k2，⋯，kn，使

β = k1α1 + k2α2 + ⋯knαn

则称β是α1，α2，⋯，αn的线性组合，β可由α1，α2，⋯，αn线性表示，β处于向量α1，α2，⋯，αn张成的空间。

线性相关与线性无关

若存在𝕂中不全为0的n个数k1，k2，⋯，kn，使

k1α1 + k2α2 + ⋯knαn = 0

则称α1，α2，⋯，αn线性相关。反之，则称α1，α2，⋯，αn线性无关。

对于线性无关的向量α1，α2，⋯，αn，若存在k1，k2，⋯，kn ∈ 𝕂，使

k1α1 + k2α2 + ⋯knαn = 0

则必有k1 = k2 = ⋯ = kn = 0

定理：只含一个向量α的向量组线性相关的充要条件为α = 0

定理：若向量组S含有零向量，则S线性相关。

定理：若α1，α2，⋯，αn是一组线性相关的向量，则任一包含这组向量的向量组线性相关。

定理：若α1，α2，⋯，αn是一组线性无关的向量，则从这一组向量中任意取出一组向量线性无关。

定理：向量α1，α2，⋯，αn线性相关的充要条件是其中至少有一个向量可以表示成其余向量的线性组合。

证明：

必要性：由k1α1 + k2α2 + ⋯knαn = 0中k1，k2，⋯，kn不全为0，可设ki ≠ 0，则有

$$\mathbf{\alpha}_{i} = - \frac{k_{1}\mathbf{\alpha}_{1}}{k_{i}} - \frac{k_{2}\mathbf{\alpha}_{2}}{k_{i}} - \cdots - \frac{k_{i - 1}\mathbf{\alpha}_{i - 1}}{k_{i}} - \frac{k_{i + 1}\mathbf{\alpha}_{i + 1}}{k_{i}} - \cdots - \frac{k_{n}\mathbf{\alpha}_{n}}{k_{i}}$$

这就说明有一个向量被表示成了其余向量的线性组合，即“至少一个”。

充分性：设αi = k1α1 + k2α2 + ⋯ + ki − 1αi − 1 + ki + 1αi + 1 + ⋯ + knαn，移项可得

k1α1 + k2α2 + ⋯ + ki − 1αi − 1 − αi + ki + 1αi + 1 + ⋯ + knαn = 0

这就说明这组向量线性相关。

定理：设α1，α2，⋯，αn，β是线性空间V中的向量，且β可表示为α1，α2，⋯，αn的线性组合，即β = k1α1 + k2α2 + ⋯knαn，则这种线性表示唯一的充要条件是α1，α2，⋯，αn线性无关。

证明：用反证法容易证明。

定理：设向量组A，B，C满足：A中任一向量都是B中向量的线性组合，B中任一向量都是C中向量的线性组合，则A中任一向量都是C中向量的线性组合。

定理：若α=(a1，a2，⋯，an)，β=(b1，b2，⋯，bn)是两个n维行向量，则α，β线性相关的充要条件是ai，bi成比例。

线性空间的基与坐标向量

线性空间的基和维数：设V是数域𝕂上的线性空间，若在V中存在线性无关的向量e1，e2，⋯，en，使得V中任一向量均可表示为这组向量的线性组合，则称\{e1，e2，⋯，en\}是V的一组基，线性空间V称为n维线性空间（即该线性空间的维数为n）并记dim𝕂V = n。如果不存在有限个线性无关的向量可以构成V的一组基，则称V是无限维线性空间。

定理：用基表示线性空间的任一向量的表示是唯一的。

证明：设对于α，有

α = a1e1 + a2e2 + ⋯ + anen = b1e1 + b2e2 + ⋯bnen

则

α − α=(a1 − b1)e1 + (a2 − b2)e2 + ⋯ + (an − bn)en = 0

因为e1，e2，⋯，en线性无关，所以a1 = b1，a2 = b2，⋯，an = bn，即表示的唯一。

坐标向量：对于n维线性空间V和对应的一组基\{e1，e2，⋯，en\}，固定基向量的次序为\{e1，e2，⋯，en\}，则线性表示

α = a1e1 + a2e2 + ⋯ + anen

表明α可与唯一的有序数对(a1，a2，⋯，an)或$\begin{pmatrix}
a_{1} \\
a_{2} \\
\cdots \\
a_{n}
\end{pmatrix}$\text{对应，称}(a1\text{，}a2\text{，}⋯\text{，}an)\text{或}$\begin{pmatrix}
a_{1} \\
a_{2} \\
\cdots \\
a_{n}
\end{pmatrix}$为α在基{e1，e2，⋯，en}下的坐标向量。并把V中所有向量在基{e1，e2，⋯，en}下对应的坐标向量构成的或n维线性空间记为𝕂n（n维行向量空间）或𝕂n（维列向量空间）。

从此，对于n维线性空间的研究就可以转换到对于𝕂n或𝕂n的研究（通常用𝕂n）。

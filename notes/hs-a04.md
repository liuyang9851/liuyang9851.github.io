速记图

1.对角相乘乘积为1（倒数关系）

$\sin\alpha \cdot \csc\alpha = 1$

$\cos\alpha \cdot \sec\alpha = 1$

$\tan\alpha \cdot \cot\alpha = 1$

2.六边形任意相邻的三个顶点代表的三角函数，处于中间位置的函数值等于与它相邻两个函数值的乘积

（商数关系）

$\sin\alpha = \cos\alpha \cdot \tan\alpha$

$\cos\alpha = \sin\alpha \cdot \cot\alpha$

$\tan\alpha = \sin\alpha \cdot \sec\alpha$

$\cot\alpha = \cos\alpha \cdot \csc\alpha$

$\sec\alpha = \tan\alpha \cdot \csc\alpha$

$\csc\alpha = \cot\alpha \cdot \sec\alpha$

3.阴影部分的三角形，处于上方两个顶点的平方之和等于下顶点的平方值（平方关系）

$\sin^{2}\alpha + \cos^{2}\alpha = 1$

$\tan^{2}\alpha + 1 = \sec^{2}\alpha$

$1 + \cot^{2}\alpha = \csc^{2}\alpha$

辅助角公式

记

$f(x) = a\sin x \pm b\cos x = \sqrt{a^{2} + b^{2}}\sin(x \pm \varphi)$

$\text{其中}\sin\varphi = \frac{b}{\sqrt{a^{2} + b^{2}}}\text{，}\cos\varphi = \frac{a}{\sqrt{a^{2} + b^{2}}}$

> $f(x)\text{的值域为}\left\lbrack - \sqrt{a^{2} + b^{2}}\text{，}\sqrt{a^{2} + b^{2}} \right\rbrack$
>
> 若$a\sin x + b\cos x = \sqrt{a^{2} + b^{2}}$，则$\sin x = \frac{a}{\sqrt{a^{2} + b^{2}}}\text{，}\cos x = \frac{b}{\sqrt{a^{2} + b^{2}}}$
>
> $\text{当}x = m\text{，}y\text{取到最大}\ /\ \text{小值时，}\tan\varphi = \frac{b}{a}$

$\arcsin x + \arcsin y = \left\{ \begin{array}{r} \arcsin\left( x\sqrt{1 - y^{2}} + y\sqrt{1 - x^{2}} \right)\ xy \leq 0\ x^{2} + y^{2} \leq 1 \\ \pi - \arcsin{\left( x\sqrt{1 - y^{2}} + y\sqrt{1 - x^{2}} \right)\ x > 0y > 0x^{2} + y^{2} > 1} \\ - \pi - \arcsin\left( x\sqrt{1 - y^{2}} + y\sqrt{1 - x^{2}} \right)\ x < 0y < 0x^{2} + y^{2} > 1 \end{array} \right.\$

$\arcsin x - \arcsin y = \left\{ \begin{array}{r} \arcsin\left( x\sqrt{1 - y^{2}} - y\sqrt{1 - x^{2}} \right) \\ \pi - \arcsin\left( x\sqrt{1 - y^{2}} - y\sqrt{1 - x^{2}} \right) \\ - \pi - \arcsin\left( x\sqrt{1 - y^{2}} + y\sqrt{1 - x^{2}} \right) \end{array} \right.\$

$\arccos x + \arccos y = \left\{ \begin{array}{r} \arccos\left( xy - \sqrt{1 - x^{2}}\sqrt{1 - y^{2}} \right) \\ 2\pi - \arccos\left( xy - \sqrt{1 - x^{2}}\sqrt{1 - y^{2}} \right) \end{array} \right.\$

$\arccos x - \arccos y = \left\{ \begin{array}{r} - \arccos\left( xy + \sqrt{1 - x^{2}}\sqrt{1 - y^{2}} \right) \\ \arccos\left( xy + \sqrt{1 - x^{2}}\sqrt{1 - y^{2}} \right) \end{array} \right.\$

$\arctan x + \arctan y = \left\{ \begin{array}{r} \arctan\frac{x + y}{1 - xy} \\ \pi + \arctan\frac{x + y}{1 - xy} \\ - \pi + \arctan\frac{x + y}{1 - xy} \end{array} \right.\$

$\arctan x - \arctan y = \left\{ \begin{array}{r} \arctan\frac{x - y}{1 - xy} \\ \pi + \arctan\frac{x - y}{1 - xy} \\ - \pi + \arctan\frac{x - y}{1 - xy} \end{array} \right.\$

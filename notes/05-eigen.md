# 05 · 特征值理论

[[toc]]

性质：上/下三角矩阵的特征值为主对角线上的元素。

任一复方阵必相似于一上三角阵。

|  | 转置 | $k$次幂 | 伴随 | 逆矩阵 | 多项式 |
| --- | --- | --- | --- | --- | --- |
| 特征值 | $\lambda$ | $\lambda^{k}$ | $\vertA\vert\lambda^{- 1}$ | $\lambda^{- 1}$ | $f(\lambda)$ |

## 对角化

$$可对角化 \Leftrightarrow \left\{ \begin{array}{r}
有n个线性无关的特征向量\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  \\
所有特征值的度数等于重数\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  \\
所有特征值中线性无关的特征向量的个数等于特征值的重数 \\
具有完全的特征向量系\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \
\end{array} \right.\ $$

$$可对角化 \Rightarrow \left\{ \begin{array}{r}
等价于单位矩阵\mathbf{I} \\
秩为n\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \
\end{array} \right.\ $$

$$可对角化 \Leftarrow \left\{ \begin{array}{r}
n个特征值各不相同 \\
实对称矩阵\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \
\end{array} \right.\ $$

### 实对称矩阵的对角化

定理：实对称矩阵必可对角化。

定理：实对称矩阵的属于不同特征值的特征向量相互正交。

定理：实对称矩阵必相似且合同于某对角阵。

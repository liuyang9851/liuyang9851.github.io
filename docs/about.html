关于本站 ​

这是刘洋的个人博客，用来放学习笔记和技术记录。

这个站点是怎么搭的 ​

  • 框架：VitePress，构建为纯静态站点
  • 公式：MathJax（构建期不渲染，浏览器端渲染），支持 LaTeX 语法
  • 托管：GitHub Pages，由 GitHub Actions 自动构建部署
  • 源码：本仓库即站点源码，改完 push 就自动发布

笔记来源 ​

线性代数部分由 Word 手写笔记迁移而来。迁移不是简单转换格式，而是按阅读 习惯重新组织：补上定理的证明思路、把性质做成速查表、把容易混淆的地方单独 说明。迁移时发现的原文笔误不会悄悄改掉，而是集中记在每篇末尾的「勘误」小节。
